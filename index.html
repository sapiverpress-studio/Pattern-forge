Pattern Forge quick guide

Best workspace: turn your device to landscape and choose Full screen. The central tile stays the main design area; open Tools, Recent or Info only when you need them.

Start

  1. Choose Start practice mode or create a named print project.
  2. Choose a drawing tool, or select Add image.
  3. The first imported image is placed on the tile automatically. Tap a thumbnail to place another copy.
  4. Select a placed motif to change its size, angle, opacity, order or position.

Preview and export

Use Preview repeat to check how your tile looks when repeated. Projects use straight, half-drop or brick repeat layouts. Export PNG for a raster image or SVG for a vector document; imported raster images remain raster inside SVG.

Save your work

Autosave stays in this browser on this device. Download editable project (JSON) to keep the editable design, or download project bundle (ZIP) for the project, PNG and SVG together. Open a JSON or ZIP project file in Pattern Forge to continue editing.

Print checks

The base tile is 4000 × 4000 pixels and exports carry 300 DPI metadata. Imported image quality depends on its original resolution and chosen print size. Check the requirements for your specific product and printer before ordering.

Keyboard

Press Escape to leave the full-screen workspace. If the Tools panel is open, its controls remain available in the drawer.
