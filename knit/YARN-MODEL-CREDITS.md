# Mathematical yarn centreline reference
The stitch engine uses the closed-form plain-knit yarn path model from:

Keenan Crane, **A Simple Parametric Model of Plain-Knit Yarns** (2023).
https://github.com/keenancrane/plain-knit-yarn

The reference code is licensed under MIT. The yarn path equations are adapted to JavaScript in \`geometry.mjs\` and combined with a new stitch chart and Canvas shading implementation in \`engine.mjs\`. The reference note is CC BY 4.0, and these files credit the author and work.

This is a mathematical **visual simulation**, not a mechanical stitch simulator, knitting pattern, or embroidery machine file. All work runs client-side. No photographic tiles or network-fetched assets are used by the new renderer.
