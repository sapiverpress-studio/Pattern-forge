# Sapiver Pattern Forge v1.2.0-alpha.3 regression record

Date: 2026-10-01

## Scope

Alpha.3 exposes the internal layer engine introduced in alpha.1/alpha.2 while keeping the v1.1.5 drawing and repeat architecture intact.

`main` and `baseline/v1.1.5` remain the protected v1.1.5 source. No deployment was performed.

## Layer controls added

- Add layer
- Rename layer
- Set layer opacity
- Show/hide layer
- Lock/unlock layer
- Include/exclude layer from export
- Duplicate layer and its artwork
- Delete layer and its artwork, while retaining at least one layer
- Move layer up/down in the visual stack
- Active layer determines where new drawn marks are created

Layers displayed at the top of the Layers panel render in front.

## Guardrails

- Hidden or locked active layers reject new drawing.
- Locking a layer clears a selected imported motif on that layer.
- Locked/hidden imported motifs cannot be reselected through the canvas.
- Imported-motif hit testing follows visual layer order, not global insertion order.
- `export:false` layers remain visible in the editor but are excluded from preview/PNG/SVG export.
- SVG export follows actual layer order.
- If the original `Motifs` layer is deleted, future imported/generated motifs fall back to an existing valid layer ID instead of producing an invalid v4 project.
- Undo/redo active-layer fallback remains valid even if a base layer has been deleted.

## Automated browser regression

Workflow: `Pattern Forge layer UI smoke test`

Successful run: `36831421492`

The final Chromium run passed the following real-browser checks:

1. Default Drawing/Motifs layer order.
2. Add and rename a Sketch layer.
3. Locked layer rejects drawing.
4. Unlocked layer accepts drawing and records the correct `layerId`.
5. `export:false` does not change editor appearance.
6. `export:false` removes the layer from SVG output.
7. Re-enabling export restores the layer to SVG output.
8. Layer opacity persists in saved project data.
9. Saved projects use `pattern-forge-v4`.
10. IndexedDB autosave restores layers and opacity after a real browser reload.
11. Duplicate layer copies its artwork.
12. Move up/down changes visual layer order.
13. Delete removes only the active layer and its artwork.
14. Imported motifs duplicated across layers are selected according to visual layer order.
15. Locking the Motifs layer clears selection and prevents canvas reselection/transform.
16. Deleting the original Motifs layer does not break later imports; imported items retain valid layer IDs.
17. No page-level or console JavaScript errors were emitted during the passing run.

Two earlier smoke runs failed because the test itself made incorrect assumptions: one asserted before the app's requestAnimationFrame UI refresh, and one assumed a duplicated Motifs layer should be above unrelated Sketch/Drawing layers rather than simply above its source layer. Those assertions were corrected; neither failure identified a product regression.

## Baseline compatibility retained

The alpha.1 regression record already established pixel/SVG compatibility with the v1.1.5 baseline across the supplied straight, half-drop and brick fixtures. Alpha.3 does not alter the repeat mathematics or existing mark-rendering algorithms.

## Not yet claimed

Alpha.3 is a development checkpoint, not a release build. The following work remains separate:

- selection/transform of drawn marks;
- Procreate-style sketch/ink/colour shortcuts;
- smarter centre/edge/object snapping guides;
- a true layer-aware eraser;
- dedicated seam-check mode;
- targeted mobile/tablet layer-UI regression.
