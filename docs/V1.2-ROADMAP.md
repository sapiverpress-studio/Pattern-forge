# Sapiver Pattern Forge — v1.2 Roadmap

This roadmap protects the proven v1.1.5 behaviour while moving Pattern Forge from a pattern-arranger-with-drawing-tools into a proper pattern illustration workspace.

## Baseline protection

- `main` remains the proven v1.1.5 baseline until v1.2 regression testing is complete.
- Development continues on `feature/layer-engine-v1.2`.
- Do not deploy v1.2 until repeat maths, autosave, project migration, exports, starter projects and browser regression checks pass.
- Preserve existing straight, half-drop and brick repeat behaviour.
- Preserve full autosave data; compact only downloadable project exports.

## Current blocker

Before adding more drawing behaviour, resolve and regression-test the layer-stack selection failure affecting overlapping motifs on different layers. Selection must follow the visible stack order.

## v1.2 implementation sequence

### 1. Layer engine and migration

- Backward-compatible `pattern-forge-v4` project format.
- Existing v1-v3 projects continue to open.
- Old imported motifs migrate to a Motifs layer.
- Old drawn marks migrate to a Drawing layer.
- Layer visibility, opacity, locking, export participation and ordering.
- Preserve old visual appearance exactly on migration.

### 2. Layer UI

- Create, rename, duplicate and delete layers.
- Reorder layers.
- Show/hide.
- Opacity.
- Lock/unlock.
- Active layer controls where new drawing is created.
- Shortcuts for Sketch, Ink and Colour layers.

### 3. Select and transform drawn artwork

Selection and transforms must work for both imported motifs and artwork created inside Pattern Forge.

- Brush strokes.
- Lines.
- Rectangles and ellipses.
- Freehand fills.
- Stamps.
- Imported images/SVG artwork.
- Move, uniform resize, rotate, duplicate and delete.
- Bring forward/send backward within the layer model.

### 4. Smart snapping and alignment

Keep automatic seamless wrapping. Do not copy Procreate's manual duplicate-and-drag edge workflow.

- Grid snapping.
- Tile edge snapping.
- Tile centre snapping.
- Artwork-to-artwork alignment.
- Temporary alignment guides.
- Clear indication that seamless edge wrapping is automatic.

### 5. Real eraser

Implement transparency-aware erasing rather than a white paint workaround.

- Erase only on the active editable layer.
- Preserve transparent backgrounds.
- Canvas rendering uses true alpha removal.
- SVG export uses an equivalent mask/clip strategy where required.

### 6. Doodle Mode

Doodle Mode is a separate creation workflow for customers who want to draw individual reusable artwork rather than construct a seamless pattern tile.

#### Entry and project behaviour

- New-project choice: **Pattern Project** or **Doodle Mode**.
- Doodle Mode does not use straight, half-drop or brick repeat maths.
- No neighbour tiles or automatic repeat copies in the normal Doodle workspace.
- Transparent background is the default.
- Users may still temporarily choose a coloured preview background, but it must not be baked into a transparent export unless explicitly requested.
- Doodles use the same brush, shape, fill, layer, selection, transform, snapping and eraser systems as Pattern Mode wherever those behaviours make sense.

#### Canvas

- Provide practical preset canvas sizes plus custom size.
- Retain high-resolution output suitable for reuse in print-on-demand and pattern work.
- Keep 300-DPI PNG metadata where applicable.
- Allow zoom/pan without changing export resolution.

#### Export

Primary action: **Export Doodle**.

- Transparent PNG with alpha.
- SVG where the artwork can be represented by the existing exporter.
- Editable Pattern Forge project JSON so the doodle can be reopened and edited.
- Optional ZIP containing PNG + SVG + editable project.
- Offer **Trim to artwork** so exported PNGs can tightly crop to the visible doodle with a small transparent safety margin.
- Also allow **Keep canvas size** for customers who need fixed dimensions.
- Never include non-printing guides in exported artwork.

#### Reuse inside Pattern Forge

A saved doodle should be importable later as a motif in a Pattern Project without requiring external background removal.

Longer-term enhancement after the first stable Doodle release: a small local **My Doodles** library could allow customers to save reusable motifs inside the app. This is deliberately not required for the first Doodle Mode release; downloadable transparent assets come first.

#### Doodle regression requirements

- Transparent pixels remain genuinely transparent after PNG export.
- Re-importing the exported PNG does not create a white rectangle/background.
- Exported bounds are correct in Trim-to-artwork mode.
- Fixed-canvas export dimensions are exact.
- 300-DPI metadata remains present where selected.
- Hidden/non-export layers and guides do not appear in output.
- Autosave/reload preserves Doodle Mode and all layers.
- Doodle project JSON reopens in Doodle Mode, not Pattern Mode.
- Existing Pattern Project exports remain unchanged.

### 7. Seam Check

Dedicated pattern inspection modes:

- Tile.
- Seam Check.
- Pattern Preview.

Seam Check should hide guides, show neighbouring tiles at full opacity and make edge joins easy to inspect without altering artwork.

### 8. Brush and workflow polish

Only after the core engine is stable:

- Brush refinements.
- Better sketch/ink/colour shortcuts.
- Presentation and mobile control cleanup.
- Additional professional print-maker workflow improvements.

## Proposed release progression

- **v1.2.0-alpha** — layer engine, migration and regression foundation.
- **v1.2.0-beta** — layer UI and stable stacking/selection.
- **v1.2.0** — complete layer workflow.
- **v1.2.1** — select/transform drawn artwork.
- **v1.2.2** — smart snapping/alignment.
- **v1.2.3** — real eraser.
- **v1.2.4** — Doodle Mode with transparent PNG/SVG/editable export.
- **v1.2.5** — dedicated Seam Check workflow.
- **v1.3** — advanced brushes and broader workflow polish.

## Protected behaviours

The following should not be rewritten casually while implementing v1.2:

- Repeat basis and lattice maths.
- Automatic edge wrapping.
- Straight/half-drop/brick export dimensions.
- PNG 300-DPI metadata.
- Existing SVG asset deduplication.
- Full autosave versus compact downloadable export behaviour.
- Existing v1-v3 project validation/migration support.
- Existing starter projects, retained as compatibility fixtures rather than immediately converting them to v4.
