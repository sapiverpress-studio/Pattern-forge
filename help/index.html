Start with the canvas

  • New Pattern asks only for the repeat structure first. Project names, customer details and other metadata do not need to block drawing.
  • New Doodle opens a blank transparent drawing canvas directly. On phones, Doodle uses landscape so the canvas has room to work.
  • Open Project is for continuing autosaved work or opening an editable Pattern Forge file.

Left tool rail

  • Select exposes move, scale, rotation, opacity, arrange, duplicate and delete controls when artwork is selected.
  • Brush shows size and opacity immediately. Open Brush Library to choose Ink, Pencil, Marker, Textured paint or Stamp.
  • Erase removes artwork only from the active layer.
  • Fill traces a closed area for a solid or gradient fill.
  • Pan moves around the canvas. Image imports artwork; Shape exposes Line, Rectangle and Ellipse.

Right palettes

  • Colour contains the current colour, palette colours, saved palettes and eyedropper access.
  • Layers exposes layer names, opacity, visibility, lock, export status, order, duplicate and delete.
  • Pattern is only shown for Pattern projects. It contains repeat preview, seam inspection, repeat visibility, grid, mirror/symmetry, construction guides and snapping.

Pattern workspace

  • Straight, half-drop and brick use the existing Pattern Forge repeat engine.
  • Use Inspect seams to show repeat neighbours at full visibility with the centre tile edge marked, then inspect joins visually.
  • The Pattern palette keeps repeat-specific controls together instead of burying them in a general Settings page.

Export and saving

  • Export PNG for a print-ready raster file with 300 DPI metadata, or SVG for scalable vector artwork. Imported raster images remain raster inside SVG.
  • Export shows the current repeat pixel dimensions and the existing source-resolution quality check before download.
  • Save an editable project JSON for portable editing, or use the ZIP project bundle for project, PNG preview and SVG together.

What stays shared

  • Pattern and Doodle use the same proven drawing, layer, selection, undo/redo, autosave and export engine underneath the new interface.
  • Start again clears placed images and drawing marks while preserving project setup, imported image library, layers and settings.
